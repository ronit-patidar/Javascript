Read -> sych vs async code 
A callback is a function that is passed as an argument to another function so that it can be called later.
Keyword	Meaning
async	Makes a function return a Promise.
await	Waits for a Promise to settle and obtains its fulfilled value, or throws its rejection reason.
try	Contains code that might throw an error.
catch	Handles errors thrown in the try block.
resolve()	Fulfills a Promise with a value.
reject()	Rejects a Promise with a reason.
